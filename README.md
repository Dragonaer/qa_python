- методу "add_new_book" были проведены валидные и невалидные проверки с помощью парамаметризации:
    1. 0 символов
    2. 1 символ
    3. 15 символов
    4. 40 символов
    5. 41 символ
    6. 42 символа
    7. 60 символов
    А так же проведена проверка на повторное добавление книги.

- методу "set_book_genre" были проведены следующие проверки:
    1. Добавление существующего жанра "Фантастика" из списка.
    2. Жанр "Романтика", отсутствующая в списке доступных, не добавляется к книге. 
    3. Книга не добавляется в список, при добавлении валидного жанра.
    4. Книга и невалидный жанр не добавляются в список.

- методу "get_book_genre" были проведены следующие проверки:
    1. Вывод жанра добавленной книги в словарь.
    2. Невозможность вывода жанра несуществующей книги в словаре.


- методу "get_books_with_specific_genre" были проведены проверки с помощью параметризации: 
    1. Вывод списка книг по валидному жанру из списка genre при добавленной книги в список
    2. Вывод списка книг по валидному жанру из списка genre_age_rating при добавленной книги в список
    3. Запрос вывода книг того жанра, которого нет в списке
    4. Запрос вывода книг невалидным жанром
    5. Запрос вывода книг при пустом словаре
    

- методу "get_books_for_children" был составлен один тест на проверку добавления книги в жанром "Мультфильмы"
- методу "add_book_in_favorites" была составлена одна проверка на добавление книги с валидными данными
